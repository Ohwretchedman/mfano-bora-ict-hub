# Mfano Africa ICT Hub

A modern, professional web platform for Mfano Africa ICT Hub, built with a focus on speed, accessibility, and clean design.

## Features

- **Multi-page Architecture**: Dedicated pages for About, Services, Courses, and Contact.
- **Modern UI/UX**: Premium Navy and Gold design system with glassmorphism and smooth animations.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **Interactive Elements**:
    - Animated stat counters.
    - Scroll reveal effects.
    - Dynamic mobile navigation menu.
    - Interactive contact forms with visual feedback.
- **Enterprise Ready**: Modular CSS and JavaScript for easy maintenance and scaling.

## Technology Stack

- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom design system using CSS variables.
- **JavaScript (ES6+)**: Centralized logic in `src/main.js`.
- **Lucide Icons**: Consistent and scalable iconography.
- **Vite**: Modern build tool for fast development.

## Project Structure

```
├── index.html          # Landing Page
├── about.html          # About Us Page
├── services.html       # Our Services Page
├── courses.html        # Courses Catalog Page
├── contact.html        # Contact Page
├── public/             # Static assets (favicons, images)
└── src/
    ├── style.css       # Global stylesheet
    └── main.js         # Core application logic
```

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
